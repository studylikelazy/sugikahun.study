## 1. 世界観【補完】

### 1.1 設定の芯

**199X年、東京。** バブルが弾けきらないまま惰性で続く景気の尾、
メーカーのワークス活動が次々と縮小し、行き場を失った技術者と設備が町工場に流れ込んだ時代。

> 大企業が捨てた実験設備が、二束三文で払い下げられていた。
> 誰も使わない風洞。誰も回さないダイナモ。
> それを買い集めた男が一人、川沿いの廃工場で、たった1台の車を作ろうとしていた。

プレイヤーはその工場を**遺言で引き継いだ**若者である。残されたのは、
鍵と、半分だけ組まれたエンジンと、「**筑波で59秒**」と殴り書きされた1枚のメモ。

### 1.2 年表

| 年 | 出来事 |
|---|---|
| 1988 | 先代（**杉原 寛治**）がメーカーの実験部を辞し、川沿いの旧紡績工場を買う |
| 1991 | 払い下げの縮尺風洞を搬入。近隣から最初の騒音苦情 |
| 1994 | 筑波で 1:02.8 を記録。当時のストリート最速級として雑誌に載る |
| 1996 | 「次は59秒だ」と言い残し、エンジンを組みかけたまま倒れる |
| **199X（ゲーム開始）** | プレイヤーが工場を相続。電気は止まり、設備は埃をかぶっている |

### 1.3 舞台

| 場所 | 役割 | 雰囲気 |
|---|---|---|
| **KOBO（工廠）** | 昼の拠点 | 旧紡績工場。高い天井、鋸屋根の天窓、油の匂い。冬は寒い |
| **C1／湾岸** | 夜の舞台 | 雨、ナトリウム灯のオレンジ、継ぎ目の音、無言の並走 |
| **辰巳／大黒PA** | 社交場 | 缶コーヒー、アイドリング、エンジンルームを覗き込む人の輪 |
| **筑波** | 審判の場 | 乾いた空気、タイヤの焼ける匂い、タイム表示のLED |
| **町** | 生活 | 商店街、町内会、金物屋、産廃業者。工場は町の中にある |

### 1.4 トーン

- **静かな狂気**。叫ばない。盛り上げない。数字が0.1秒縮んだときの、独りの小さな拳。
- ノスタルジーは「懐かしさ」ではなく「**取り返しのつかなさ**」として描く。
- 走り屋は不良ではなく職人。礼儀と技術を重んじる集団として描く（`09` §6 倫理方針と整合）。

## 4. オーディオ

### 4.1 エンジン音合成（最重要）

サンプルの単純ループでは本作は成立しない。**部品構成で音が変わる**必要がある。

| 手法 | 用途 |
|---|---|
| **RPMレイヤー・クロスフェード** | 基本。1,000 rpm 刻みの収録素材を2–3層ブレンド |
| **グラニュラー伸縮** | 中間rpmの滑らかな接続。ピッチと粒度をrpmに追従 |
| **負荷レイヤー** | オン／オフスロットルの2系統を負荷でクロスフェード |
| **気筒数・爆発間隔の再構成** | 直4／直6／V6／ロータリーで**パルス列自体を変える**（位相合成） |
| **排気系フィルタ** | マフラー容量・パイプ径・触媒有無を**EQ＋共鳴フィルタ**で再現 |
| **過給音** | タービンの回転数に連動したサイン系の「ヒュイーン」。`J_turbo` が小さいほど立ち上がりが速い |
| **BOV／ウェイストゲート** | スロットルオフ時のイベント音。部品で音色が変わる（大気開放／循環） |
| **環境** | トンネル／高架下／オープンでリバーブ送り量とプリディレイを自動変化 |

```
出力 = Σ(rpmレイヤー × 負荷ブレンド) → 排気系EQ → 共鳴 → ドップラー → 空間リバーブ
     + タービン音 + インダクションノイズ + メカノイズ（タペット、チェーン）
     + 車外音（風切り、タイヤ、路面継ぎ目）
```

> **検証基準**：音だけを聞いて「NAの高回転型」「ドッカンターボ」「ロータリー」の区別がつくこと。

### 4.2 工場のサウンドスケープ

- 機械ごとに**ループ（基音）＋ランダム・ワンショット**（切削の抜け、エアの排気、リレーの音）。
- 同種の機械が増えても**音が濁らない**よう、同時発音を空間的に間引き（距離・優先度でボイス制限）。
- 「静けさ」を設計する：全機械停止時は、換気扇と雨音だけになる。この落差が工場の生命感を作る。
- 特別な音：ベルトが初めて動く音、計測器が `S` を刻印する音、研究完了のチャイム。

### 4.3 音楽

| 場面 | 方向性 |
|---|---|
| 工場（昼） | アンビエント／ミニマル。機械音に溶ける。メロディは控えめ |
| 夜・流し | シティポップ風のインスト、低域の効いたテクノ |
| 夜・バトル | ユーロビート直系は避け、**90年代の日本的ハイエナジー**を独自解釈。BPM 150–165 |
| 筑波 | 無音に近い。エンジンと風の音だけ。タイム表示の瞬間だけ短いスティンガー |
| エンディング | ピアノとギターの小編成 |

すべてオリジナル楽曲。既存曲の使用は行わない（`09` §5.3）。

### 4.4 ミックス

| 規則 | 内容 |
|---|---|
| ダッキング | 重要な通知（故障、検問、研究完了）で BGM −6 dB |
| 距離減衰 | 工場は対数減衰＋遮蔽（壁で −8 dB） |
| ラウドネス | −16 LUFS 目標。夜パートのみ −14 LUFS |

### 5.2 情報設計の原則

1. **常時表示は4つだけ**：時刻／資金／DATAレート／警告。それ以外は呼び出し。
2. **数値には必ず単位と基準**（`+12 PS (+4.2%)`、`−0.18 s/lap`）。
3. **因果のリンク**：どの数値からでも「なぜこの値か」を辿れる（クリックで寄与度の内訳を開く）。
4. **色だけで情報を伝えない**（形・記号・テキストを併用。色覚多様性対応）。
5. **モーダルを多用しない**。インスペクタは右サイドのドロワーに統一。

## 7. 文言とローカライズ

### 7.1 ボイス＆トーン

- 短く、断定的に。技術用語は正式名称を使い、ツールチップで補足する。
- プレイヤーを褒めすぎない。達成の表現は数値そのもの。
- 例：
  - ✅「第2ヘアピンの立ち上がりで 0.14 秒失っている。トラクション不足。」
  - ❌「すごい！もう少しで最高記録です！頑張って！」

### 7.2 ローカライズ

| 項目 | 方針 |
|---|---|
| 対応言語 | 日本語（原語）／英語。中国語簡体字はEA中に判断 |
| 文字列管理 | すべて `locale/<lang>/*.json`。コード内に直書き禁止 |
| 文字数 | 日本語を基準に、英語は 1.6 倍の幅を確保してレイアウト |
| 単位 | メートル法固定（km/h、kg、mm）。英語版でも変更しない（JDM文脈のため）。ただし `PS/hp` は切替可 |
| 固有名詞 | 「首都高」「C1」「筑波」は英語版でもローマ字表記を維持（`Shutoko`, `Tsukuba`） |
| フォント | 日本語：UDゴシック系＋等幅（数値）。英語：Inter / IBM Plex Mono |
