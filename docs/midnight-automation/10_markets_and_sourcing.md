# 10. 調達 ― 4つの市場とランダム性の設計

> 「作れないものは、買うしかない。買ったものは、たいてい裏切る。」

> ⚠ **正本は [`spec/S3_four_markets_tables.md`](spec/S3_four_markets_tables.md) へ移管した**（判断ログ D-15）。
> 市場の内訳は **国内中古／輸入車／コンテナ／ローカル** の4大市場へ再定義され、
> 国内中古はさらに AA・ネトオク・解体ヤード・青カゴの4チャネルに分かれる。
> 本書は**ランダム性の設計思想**（§1・§8 の7原則）と**旧構成の記録**として残す。
> 具体的な確率表・価格表・抽選ロジックは S3 を参照すること。

本書は **パーツとベース車をどこから手に入れるか** の設計思想である。
参照実装は [`shared/midnight/market.ts`](../../shared/midnight/market.ts)（テスト52件）にある。

## 1. 設計の出発点：なぜ「4つ」なのか

工場で何もかも作れるなら市場は要らない。市場が万能なら工場が要らない。
この2つを両立させるために、**市場は「工場の下流」ではなく「工場の入口」** に置く。

さらに重要なのは、**ランダム性を1か所に集めない**ことだ。
乱数が1本の太いダイヤルになっていると、プレイヤーの体験は「運が良い日／悪い日」に潰れる。
そこで**乱数の軸を4本に分解し、それぞれ別の市場に担当させる**。

| 市場 | ID | 乱数の軸 | 価格帯（定価比） | 等級上限 | 解放 |
|---|---|---|---|---|---|
| **カタログ**（正規流通） | `catalog` | **ほぼ無し**（相場指数のみ） | ×1.00 | B（受注生産で A） | Act0 |
| **ヤード**（解体・部品取り） | `yard` | **状態（品質）** | ×0.08 – 0.38 | A（ただし摩耗で実効低下） | Act0 |
| **深夜オークション** | `auction` | **出現・レアリティ・競合** | ×0.3 – 6.5 | S（幻級のみ） | Act1 |
| **コネクション**（夜の人脈） | `connection` | **解放条件**（評判・ヒート） | 金銭以外の対価あり | **LEGENDARY（ここだけ）** | Act2〜（評判30〜） |

この分解により、プレイヤーは状況に応じて**どの乱数を引き受けるかを選べる**ようになる。

- 納期が切迫 → カタログ（乱数を引き受けない。金で確実性を買う）
- 金がない → ヤード（品質の乱数を引き受ける）
- 相場を読める → オークション（競合の乱数を引き受ける）
- 夜を走っている → コネクション（時間と評判を先に払っている）

> **判断**：「全部入りのガチャ商店」を1つ置く案は却下した。
> 乱数は**分解されて初めて戦略になる**。1本にまとめた瞬間に、それはただの運になる。

## 2. 共通ルール

### 2.1 完全決定論（判断ログ D-06 の帰結）

すべての在庫は次式から生成される。

```
seed = hash32(saveSeed, 市場ID, 週番号)
```

**同じセーブの同じ週なら、何度リロードしても品揃えも価格も競合も同一**。
これは単なる実装都合ではなく、次を同時に満たすための設計である。

- リプレイ・ゴースト・ベンチマークが壊れない（`07` §3）
- **セーブスカムで品揃えを引き直せない**（オートセーブ方式と組み合わせる）
- 「先週の相場」をプレイヤーが記録・予測できる＝**市場が学習対象になる**

### 2.2 相場指数

週ごとに全体相場が 8週周期で 0.82〜1.18 の範囲をゆっくり波打つ（週あたりの変動は 0.08 以下）。
さらにスロット別の**ブーム補正 ±8%**（3週ごと）が乗る。最終レンジ 0.70〜1.30。

> ブームは夜のイベントと連動させる（例：雑誌に大径タービンの特集が載った週は `turbo` が高騰）。
> **プレイヤーの行動が相場を動かす**：Act6 で自作 Legendary 品を大量出品すると、そのスロットの指数が下がる。

### 2.3 等級の天井 ― 工場を守るための最重要ルール

| 等級 | 市場で手に入るか |
|---|---|
| C / B | カタログで無限に買える |
| A | 受注生産（高額・納期7日）／ヤードの極上個体／オークションの希少 |
| **S** | **オークションの「幻」級のみ**。年に数回しか出ない |
| **LEGENDARY** | **買えない**。自分で選別・摺り合わせるか、コネクションの一点物のみ |

**金で Legendary 級が揃うなら、この作品の工場は存在意義を失う。**
市場はあくまで「C〜A級の素材と、作れないものへの近道」であり、頂点には届かない。

## 3. 市場1：カタログ（正規流通）

**乱数を引き受けない市場。** 詰まったときの保険であり、自動化の最初の対象。

| 項目 | 仕様 |
|---|---|
| 在庫 | 無限。解放済みの全部品が常に買える |
| 価格 | 定価 × スロット相場指数 |
| 納期 | 1日（¥400,000 未満）／3日（以上）。速達 +40% で即日 |
| 等級 | **B 固定**。受注生産（Act2〜）で **A 保証**、価格 ×2.6・納期7日 |
| 状態 | 新品（100%）。瑕疵なし |

### 3.1 「つまらない」ことが仕事

カタログは意図的に退屈に作る。**ここで悩ませてはいけない。**
悩みどころは「カタログで済ませるか、自分で作るか／ヤードで博打を打つか」という**一段上の判断**に置く。

```
カタログのB級ピストン4本  = ¥368,000・即日・確実
自社製のA級ピストン4本    = ¥90,000相当の材料＋ライン占有6時間＋歩留まり62%
ヤードの中古4本          = ¥48,000・ただし2本は割れているかもしれない
```

この3択が毎回成立していれば、カタログは役目を果たしている。

## 4. 市場2：ヤード（解体・部品取り）

**状態のガチャ。** 本作でいちばん「開ける瞬間」が楽しい市場。

| 項目 | 仕様 |
|---|---|
| 入荷 | 毎週月曜 06:00、**8〜16 ロット**。現物一点物 |
| 状態 | 平均 **0.45**・σ0.22（0.05–0.95）。**半分以上はハズレ** |
| 価格 | 定価 × (0.08 + 0.30 × 見かけの状態) × 指数 ＝ 定価の **8〜38%** |
| 瑕疵 | クラック `18%×(1−状態)` / 固着 `30%×(1−状態)` / 欠品 `12%` / 贋作 `3%` |
| 表示 | 未鑑定では状態が **±0.25 の帯**でしか分からない。瑕疵は見えない |

### 4.1 価格は「弱いシグナル」にする

売り手も素人ではないので、程度の良い個体には高い値が付く。
ただし値付けは**見かけ**（真の状態 ± 0.15 のノイズ）に基づく。
つまり **「安い掘り出し物」は実在するが、確実には見分けられない**。
プレイヤーが読むべきなのは「価格そのもの」ではなく「価格と表示帯の矛盾」になる。

### 4.2 床（確定枠）

**毎週、必ず1ロットは状態0.6以上の「使える個体」が並ぶ**（クラック・固着・贋作なし）。
これは回帰テストで強制している。乱数で詰む週を作らないための保証である。

### 4.3 ハズレの出口 ― 解体

ヤードの品は、使えなくても捨て札にならない。

```
素材回収量 = 質量 × (0.55 + 0.40 × 状態)
D2データ   = 2 + 8 × 状態        … 分解して寸法を測る＝リバースエンジニアリング
D3データ   = 1 + 4 × 状態        （定価¥200,000以上の部品のみ）
```

**他人が作った部品を測ることは、それ自体が研究の入力になる。**
Act5 で解体ラインを組めば、この工程は全自動になる（§8）。

## 5. 市場3：深夜オークション

**出現と競合のガチャ。** 夜パートと同じ時間帯に動く、本作の「勝負」の市場。

| 項目 | 仕様 |
|---|---|
| 出品数 | 週 **10 + 2×Act** 本（10〜22）。締切はゲーム内 D1〜D7 に散る |
| レアリティ | 並 **70%** / 希少 **25%** / **幻 5%** |
| 価格倍率 | 並 ×1.0 / 希少 ×2.2 / **幻 ×6.5** |
| 想定落札額 | 定価 × 倍率 × (0.35 + 0.55×状態) × 指数 × (0.90 + 0.03×★) |
| 開始価格 | 想定額 × 0.35 |
| 競合 | **1〜4人**。各自の指値は想定額 × U(0.60, 1.10)、その最大値が壁になる |
| 贋作 | `0.5% + 14% × (5−★)/4` ＝ ★5 で 0.5%、★1 で **14.5%** |
| 幻級の対象 | **定価 ¥150,000 以上の部品のみ**（「幻のスプリング」は興醒めなので出さない） |

### 5.1 二位価格方式

**落札しても、支払うのは「競合の最高指値 +1%」だけ。**

```
あなたの上限 ¥800,000、競合の壁 ¥410,000 → 落札額は ¥414,100
```

これにより「**上限額を正直に入れるのが最適戦略**」になる。
小刻みな入札合戦や、終了3秒前のスナイプ職人芸を要求しない。
本作が問うのは反射神経ではなく、**その部品にいくらの価値があると見積もったか**である。

> 結果画面では競合の壁を**必ず開示**する。負けた入札も「相場の学習データ」として返す。

### 5.2 天井（ピティ）

幻級を引けない週が続くと出現率が上がる：`5% + 1%×連続週`（**上限 15%**）。
落札すればリセット。隠しパラメータだが、UIには「最近の幻級の出現」履歴として間接的に示す。

### 5.3 贋作という緊張

★の低い出品は安いが贋作を掴む。贋作は**組み付けてから壊れる**（走行中に砕ける＝夜の事故）。
鑑定（§7）で事前に判別できるので、これは「情報を買うかどうか」の判断に還元される。

## 6. 市場4：コネクション（夜の人脈）

**金では開かない市場。** ここだけが Legendary 級と設計図に触れられる。

| 項目 | 仕様 |
|---|---|
| 解放 | 評判（REP）**30 ごとに1枠**（最大3枠）。各枠は週55%で出現 |
| 閉鎖 | **ヒート70以上の週は提示ゼロ**（裏ルートが店を閉める） |
| 品目 | ワンオフ部品（S/LEGENDARY）50% / **設計図**（レシピ解放・A級）35% / 一点物の車体 15% |
| 対価 | 金銭 45% / **データ** 25% / **指定ライバルに勝つ** 20% / **車を数日貸す** 10% |
| 期限 | 3〜7日で消える。保留は効かない |

対価が金銭でないことが本質である。

- **データ**：「お前の80Rのログを全部よこせ」＝研究資源の供出
- **勝負**：「環状のアイツに勝ってこい」＝夜パートへの強制送還
- **貸与**：「3日貸せ」＝**その間ヒーローカーが使えない**＝週末のアタックを1回捨てる

> これは報酬系であると同時に**物語の配給路**でもある。登場人物は在庫リストの形で現れる。

## 7. ベース車の入手

ヒーローカーは1台。だから**ベース車選びはビルドの方向性そのもの**であり、
「何度も引くガチャ」ではなく「数回しか引かない重い決断」として設計する。
ガレージ枠は3台（Act5で5台）。部品取り車・テスト車・貸出用を持てる。

### 7.1 素性パラメータ

| パラメータ | 内容 | 効き方 |
|---|---|---|
| 走行距離 | 5千〜240千 km | 消耗、オーバーホール費 |
| **フレーム歪み** | 0〜8 mm | **剛性 −0.045/mm**。>6mm は**矯正不能** |
| 腐食 | 0〜1 | 剛性 −0.08、溶接工数 |
| 修復歴 | bool | 歪みの事前確率、売却価値 |
| ワンオーナー | bool | 当たり個体の指標、価格 ×1.35 |
| ナンバー | bool | 無しは**公道（夜パート）に出られない**＝サーキット専用 |

```
剛性係数   = 1 − 0.045 × 歪みmm − 0.08 × 腐食
矯正費用   = ¥45,000 × 歪み^1.4 + 腐食 × ¥180,000   （日数 = ceil(1.5×歪み + 6×腐食)）
実効グリップ = μ0 × clamp(0.88 + 0.12 × 剛性係数, 0.60, 1.05)   （剛性係数 1.0 = 新車）
```

**剛性係数 0.80 の車体は、どんな部品を奢っても μ が 2.4% 落ちる＝筑波で約 +0.6 秒。**
`08` §7.1 の感度表に照らせば、これは 400 PS 分の努力を帳消しにする。
**車体が歪んでいたら、エンジンを何基作っても報われない。** この一点を数値で突きつける。

### 7.2 市場別の分布

| 市場 | 台数/週 | 走行距離 | 歪み | 価格（新車比） | 性格 |
|---|---|---|---|---|---|
| カタログ（認定中古） | 最大3（解放済み車種から重複なし） | 5–40千 km | **0 mm 保証** | ×0.75–0.95 | 高いが完全に安全 |
| ヤード（不動・事故） | 2–4 | 90–240千 km | 55%の確率で 0–8 mm | **×0.03–0.12** | 激安。地雷を踏むと全損 |
| オークション | 2–5 | 20–180千 km（修復歴28%） | 修復歴あり 0–6 / なし 0–1 | ×0.12–0.55 | **当たりもハズレもここ** |
| コネクション | 稀 | — | 0 | 対価は金銭以外 | ナンバー無しの競技車体 |

> 実際の生成例（seed 20261016・第2週）：**葉山 エヴォル IV ¥131,400。**
> 走行11.2万 km、歪み **7.9 mm**、腐食63% → 剛性係数 **0.59**、矯正費 ¥926,194／16日、**矯正不能**。
> 安い理由は必ずある。¥8,000 の鑑定を惜しんだ者だけが、これを掴む。

## 8. ランダム性の7原則

本作の乱数設計は、この7条から外れてはならない。

| # | 原則 | 実装 |
|---|---|---|
| 1 | **決定論**：引き直させない | `hash32(saveSeed, 市場, 週)`、オートセーブ |
| 2 | **分散は買える**：乱数＝運ではなく**情報の不足** | 鑑定・計測ライン・相場ロガー |
| 3 | **床がある**：どの週も最低限は回る | ヤードの確定枠、カタログは常に全品 |
| 4 | **天井がある**：不運が続かない | 幻級のピティ（5%→15%） |
| 5 | **ハズレが素材になる** | 解体＝素材 + D2/D3データ |
| 6 | **期待値を隠さない** | EV と分布をUIに常時表示 |
| 7 | **時間が必ず解決する** | 週次更新。詰みは存在しない |

### 8.1 鑑定 ― 分散を金で縮める

| レベル | 手段 | 費用 | 表示帯 | 瑕疵の開示 |
|---|---|---|---|---|
| 0 | 写真と説明文だけ | ¥0 | **±0.25** | なし |
| 1 | 簡易鑑定（業者） | ¥8,000 | ±0.10 | 贋作・欠品のみ |
| 2 | **自社の計測ライン**（CMM） | ¥0（電力のみ） | **±0.03** | **全て** |

**レベル2が無料である**ことが設計の肝である。
工場を育てた者だけが、市場のランダム性を事実上無効化できる。
——「自動化が進むほど、博打が博打でなくなる」。これが本作の成長実感の形である。

## 9. 市場の自動化ロードマップ

ここが本作らしさの本丸。**ガチャを引く作業そのものを、工場に組み込んで消す。**

| Act | 解放 | 内容 |
|---|---|---|
| 0 | 購買端末 | 手動発注。カタログとヤードのみ |
| 1 | オークション口座 | 深夜の入札に参加できる |
| 2 | **自動発注** | 回路網（`02` §12）から「在庫 < N で発注」。ベルトの末端が発注信号を出す |
| 3 | **相場ロガー** | 価格履歴グラフ、スロット別指数、EV表示。**情報で分散を縮める** |
| 4 | **入札エージェント** | ルール（スロット／上限倍率／最低状態／最低★／最大落札数／予算）を書くと自動で競る |
| 5 | **解体ライン** | ヤードの箱を自動開封 → 洗浄 → 分解 → 計測 → 素材とD2/D3に変換。**ガチャの工業化** |
| 6 | **出品・裁定** | 自作品を相場高騰時に出品。ただし週2点まで（量産はしない＝P1） |

```
[オークション監視] ─(落札)→ [荷受けバッファ] ─→ [洗浄] ─→ [分解] ─┬→ [計測CMM] → D2/D3
                                                                  ├→ [使える部品] → 部品倉庫
                                                                  └→ [屑材] → 溶解炉
```

Act5 のプレイヤーは、もはや1点ずつ値踏みしない。
**「状態0.5以上のタービンを相場の90%以下で、週3つまで」というルールを書いて寝る。**
朝、ラインの端から選別済みの部品とデータが流れ出している。これが到達点である。

## 10. UI / UX

### 10.1 市場画面（昼・工場内の購買端末）

```
┌─ 調達端末 ─────────────────── 第12週 / 相場指数 1.04 ↗ ─┐
│ [カタログ] [ヤード 16] [オークション 16] [コネクション 2] │
│                                                          │
│  ヤード — 現物一点物・返品不可                            │
│  ┌────────────────────────────────────────────────────┐  │
│  │ GTウィング（大・1700mm） ¥60,400  定価の 31%       │  │
│  │ 状態 [▓▓▓▓▓▓░░░░] 40–90%  ← 鑑定で ±3% まで絞れる │  │
│  │ 期待値 ¥75,957（+26%）  瑕疵: 不明                 │  │
│  │                      [鑑定 ¥8,000] [計測ライン] [買う]│
│  └────────────────────────────────────────────────────┘  │
└──────────────────────────────────────────────────────────┘
```

- **期待値（EV）と提示価格の差**を常に併記する。隠した方が射幸心は煽れるが、本作はそれをしない。
- 状態バーは**帯**で描く。点ではなく幅で見せることが、このゲームの不確実性の表現である。
- 鑑定ボタンは常に見えている。**「情報を買え」というメッセージを画面から消さない。**

### 10.2 オークション画面（夜・スマホ的UI）

夜パート中、走行の合間に**車内のスマホで入札できる**。
締切が近い出品は HUD の端に小さく通知が出る。
首都高を流しながら、信号待ちで ¥800,000 の上限を入れる——この体験が本作の二大柱を繋ぐ。

### 10.3 禁止事項

- 演出つきの開封ガチャ（回転するルーレット、虹色のエフェクト）は**作らない**。
- 課金・リアルマネーとの接続は**絶対に作らない**（`09` §6 倫理方針）。
- 確率を隠した「確定演出」は作らない。開示される数字がすべて。

| `02` 工場 | 自動発注（回路網）、解体ライン、計測ラインによる無料鑑定 |
| `03` 車両 | 中古部品は `PartInstance.wear` に状態が入る。車体剛性がμに効く |
| `04` 夜 | 評判→コネクション解放、ヒート→裏ルート閉鎖、車内スマホでの入札 |
| `05` 研究 | 解体によるD2/D3、設計図によるレシピ解放（研究のショートカット） |
| `05` 経済 | 支出の主要項目。相場変動が資金計画に効く |
| `07` 技術 | 市場生成は決定論tickの外（週境界で1回）。生成コストは300週で1.5秒未満 |

### 11.1 研究との関係 ― 設計図は「研究の近道」であって「代替」ではない

コネクションの設計図はレシピを1つ解放するが、**研究ノードそのものは開かない**。
つまり「作れるようにはなるが、その原理を理解したことにはならない」。
派生ノードへ進むには結局 DATA を払う必要がある。

## 12. 失敗モードと対策（デザインリスク）

| リスク | 兆候 | 対策 |
|---|---|---|
| ガチャ疲れ | ヤードを毎週16件も吟味させられる | EV表示・絞り込み・Act4以降の自動化で**作業を消す** |
| セーブスカム | 良い個体が出るまでリロード | 決定論シード＋オートセーブ |
| 市場が工場を陳腐化 | 「買った方が速い」 | 等級上限（S/LEGENDARYは買えない）、納期、相場高騰 |
| 資金過多で無意味化 | 終盤に金が余る | 幻級とコネクションは**金で買えない**供給制限 |
| 乱数で詰む | 必要部品が3週出ない | 床（確定枠）、カタログ常時在庫、受注生産 |
| 地雷が理不尽 | 歪み8mmを掴んで萎える | 鑑定で**必ず事前に分かる**。掴むのは情報を買わなかった選択の結果 |

> 最後の行が本作の姿勢である。**理不尽な乱数は置かない。置くのは「調べなかった」という自己責任だけ。**
