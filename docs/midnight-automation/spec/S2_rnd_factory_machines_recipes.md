## 3. 主要実験・加工施設（本作の花形）

### 3.1 風洞実験棟（Wind Tunnel）

| 項目 | 値 |
|---|---|
| サイズ | 12×6 タイル（送風機棟 4×6 ＋ 測定部 8×6） |
| 電力 | **420 kW**（送風機）＋ 18 kW（計測系） |
| 騒音 | 104 dB（**近隣圧の主犯**。防音壁と夜間停止が要る） |
| 入力 | クレイモデル ×1 ／ スモーク液 **12 L/サイクル** ／ 圧縮空気 200 L/s |
| 出力 | **D6 ×（§3.1.2 の式）** ＋ 風洞データカートリッジ ×1 |
| 1サイクル | 1,800 tick（90 s） |

#### 3.1.1 クレイモデル成形ライン（必須の前段）

```
工業用粘土 ×8 ─► [粘土ミキサー 240t] ─► 粘土ブロック ─► [5軸クレイミル 900t]
      ▲                                                        │
   温水 40℃ 20L/t                                              ▼
                                               クレイモデル（形状パラメータ付き）
```

クレイモデルは **形状パラメータ**（ウィング角、リップ長、ディフューザー角、車高）を保持する。
同じ形状を2回測っても同じ結果しか出ない＝**探索空間を自分で動かす**必要がある。

#### 3.1.2 D6 産出の式

```
D6 = round( baseD6 × k_smoke × k_scale × k_novelty )

  baseD6   = 6
  k_smoke  = clamp(スモーク液供給量 / 12 L, 0.4, 1.3)      … 可視化の密度
  k_scale  = 模型スケール 1/5 → 0.7 ／ 1/2 → 1.0 ／ 実車 → 1.35
  k_novelty= 1.0 + 0.8 × (今回の形状パラメータと既測点の最小距離 / 正規化距離)
             ※ 同じ形状を測り続けると 1.0 → 0.2 まで減衰（**総当たりの禁止**）
```

得られた空力係数は `03` §8 の `Cl/Cd` に直結し、S5 のラップ計算にそのまま入る。

### 3.2 エンジン破壊ベンチ（Destructive Engine Bench）

**あえて壊す設備。** 壊れた瞬間にだけ出るデータがある。

| 項目 | 値 |
|---|---|
| サイズ | 8×8 タイル（防爆室 ＋ 制御室） |
| 電力 | 180 kW（負荷吸収ダイナモ・回生 −40 kW） |
| 騒音 | 112 dB（**最大の騒音源**。地下化 or 夜間限定運用） |
| 入力 | 試作エンジン ×1（＝ピストン4＋コンロッド4＋クランク1＋ヘッド1） |
| 流体 | 高オクタン試験燃料 **0.8 L/s**、冷却水 60 L/s、エンジンオイル 12 L/s |
| 出力 | **D3**、破壊試験記録 ×1、破壊片（産廃）、まれに**無傷の生存部品** |
| 1サイクル | 可変（§3.2.1） |

#### 3.2.1 破壊までの時間と D3 産出

```
負荷率 L   = 設定（0.6〜1.4）。1.0 = 定格全負荷
回転数 N   = 設定（rpmLimit の 0.8〜1.15 倍）
燃料ON     = 100 / 102 / 105

寿命(tick) = baseLife × q^3 × exp(−2.4 × (L − 1)) × (N_ratio)^−5.2 × k_fuel
  baseLife = 2,400
  q        = 組んだ部品の平均品質係数（C 0.90 / B 1.00 / A 1.06 / S 1.12 / LEGENDARY 1.18）
  k_fuel   = ON100 0.85 ／ ON102 1.00 ／ ON105 1.18

D3 = round( 14 × (L^1.8) × (N_ratio^2.2) × k_fuel ) ＋ 破壊ボーナス 40
     ※ 壊さずに終了（タイムアップ）した場合は破壊ボーナスなし
```

**設計意図**：`寿命` は負荷の指数関数なので、**ギリギリを攻めるほど短時間で大量のデータ**が出る。
ただし部品は消える。「良い部品を壊す」ことの心理的抵抗そのものがゲームになる。

> 生存部品の確率 `p_survive = clamp(0.35 − 0.25×(L−1) − 0.3×(N_ratio−1), 0.02, 0.6)`。
> Legendary 部品を壊す前に、ここに賭けるかどうか——という一瞬がある。

### 3.3 オートクレーブ（高温高圧釜）

| 項目 | 値 |
|---|---|
| サイズ | 6×10 タイル |
| 電力 | 260 kW（昇温時のみ。保持は 80 kW） |
| 入力 | カーボン積層プリフォーム ×1、エポキシ樹脂 24 L、圧縮空気（バギング） |
| 出力 | **ドライカーボン外板／モノコック構成材** |
| 1サイクル | 6,000 tick（5 分）＋ 昇降温 |

#### 3.3.1 硬化プロファイル（プレイヤーが設計する）

```
温度カーブ：t0→t1 昇温(℃/min)、保持温度 Th(℃)、保持時間 Hh(min)、降温(℃/min)
圧力カーブ：加圧 P(bar)、真空度 V(kPa)

強度係数 S = f_cure × f_void × f_fiber
  f_cure = exp( −((Th − 177)^2) / 420 ) × clamp(Hh / 120, 0.5, 1.15)
  f_void = clamp(1.10 − 0.04 × ボイド率(%), 0.6, 1.1)
      ボイド率(%) = max(0, 3.2 − 0.28×P[bar] − 0.015×V[kPa] + 0.4×(昇温速度[℃/min] − 2))
  f_fiber= プリプレグ等級（C 0.92 / B 1.00 / A 1.05 / S 1.10 / LEGENDARY 1.16）

質量 = 設計質量 × (1 + 0.02 × ボイド率)        … 失敗作は重い
剛性寄与 = 基準剛性 × S                        … S4 のモノコックに直結
```

**昇温が速いと安いが脆い。** 遅いと電力と時間を食う。これが Act5 の中心的なトレードオフ。

### 3.4 メインフレーム（スパコン）

| 項目 | 値 |
|---|---|
| サイズ | 10×8（演算ラック ＋ 冷却塔） |
| 電力 | **1 ラック 140 kW**（最大 8 ラック ＝ 1,120 kW） |
| 冷却 | **液体窒素 1.2 L/s ／ラック**。供給が切れると 30 s でサーマルスロットリング → 演算破棄 |
| 入力 | 走行ログテープ、風洞データカートリッジ、破壊試験記録 |
| 出力 | **点火マップ**、**サスジオメトリ解**、**空力最適化案**、**セットアップ候補** |

#### 3.4.1 演算の式

```
処理量[tick] = 問題規模 / (ラック数 × 0.92^(ラック数−1) × clamp(LN2供給率, 0, 1.15))
  ※ 0.92^(n−1) は並列化効率の逓減。**8ラックでも 5.6 ラック分の性能**

問題規模：点火マップ 18,000 ／ サスジオメトリ 26,000 ／ 空力最適化 64,000 ／ 全体最適 180,000

解の品質 Q = clamp( 0.55 + 0.1×log2(ラック数) + 0.25×(入力データ鮮度) − 0.3×(スロットリング率), 0, 1 )
  入力データ鮮度 = exp(−経過ゲーム日 / 9)       … 古いログは価値が落ちる
```

得られた解を適用すると、`driveability` と各セットアップ値が自動調整される（S5 §7）。
**Act6 の自動探索（CMA-ES）はここで回す。**計算資源＝電力＝デマンド＝金。

## 5. 電力・熱・騒音（外部性）

| 項目 | 式 |
|---|---|
| デマンド | 直近 600 tick の平均 kW。契約 kW の **1.3 倍**で遮断、違約金 ¥50,000＋翌月契約増 |
| 電気料金 | 基本 `契約kW × ¥1,650/月` ＋ 従量 昼 ¥22 / 夜 ¥12 per kWh |
| 熱 | 機械ごとに `heatKw`。室温 = 外気 + Σheat/換気能力。**室温 +1 ℃ で σ_proc +1.8%** |
| 騒音 | `dB_total = 10·log10(Σ 10^(dB_i/10))`、距離減衰 −6 dB/倍距離、防音壁 −12 dB |
| 近隣圧 | `NUISANCE += (dB_境界 − 55) × 0.02 /分`（夜間は係数 ×2.5） |

> **夜間の工場運転が強力だが危険**：電気は安い（¥12）が、騒音の係数が 2.5 倍。
> 磁気浮上コンベアと EDM は無騒音なので、終盤は「夜に静かに回る工場」を目指すことになる。

## 6. 公差・品質システム（Legendary への道）

### 6.1 等級

| 等級 | 寸法公差 | 品質係数 q | 意味 |
|---|---|---|---|
| C | ±0.100 mm | 0.90 | そのへんの汎用旋盤 |
| B | ±0.050 mm | 1.00 | 基準。市販品相当 |
| A | ±0.020 mm | 1.06 | 精密ライン |
| S | ±0.008 mm | 1.12 | 恒温室＋研削＋ホーニング |
| **LEGENDARY** | **±0.003 mm** ＋ セット内重量差 **≤ 0.001 g** | **1.18** | 選別・摺り合わせ済みの神品質 |

> 註：`0.001 g` は実機の常識（レース用ピストンの重量合わせは ±0.2 g 程度）を超える値だが、
> **本作の「伝説品質」の象徴として意図的に採用**している。ゲーム内では 0.0001 g 分解能の
> 精密天秤でこれを測る、という設定で一貫させる。

### 6.2 公差の生成式（1クラフトごと）

```
σ_eff = σ_machine
      × (1 + 1.8×(室温 − 20.0)/10)             … 恒温室で殺せる
      × (1 + 2.6×toolWear^2)                   … 工具摩耗が効く（二次）
      × (1 + 1.2×fluidContamination)           … 切削油の汚れ
      × (1 − 0.35×calibration)                 … CMM 接続で calibration=1.0
μ_drift = driftPerTick × ticksSinceCalibration  … 系統誤差（刃物の逃げ）

誤差 e ~ N(μ_drift, σ_eff)    → |e| を等級表に照合して等級決定
入力等級の継承：上流が A 以下なら、下流は**入力等級 +1 段**までしか上がらない
```

### 6.3 Legendary の作り方（R22 ブループリント選別）

```
同一レシピの部品を n 個投入 → 実測値の分布から「中心に最も近い 1 個」を選ぶ
p(LEGENDARY) = Φ(0.003/σ_eff) ^ 1   × 摺り合わせ成功率(0.86)
期待回数     = 1 / p
```

σ_eff = 0.004 mm のラインなら p ≈ 0.46 → 2〜3個で 1個。
σ_eff = 0.012 mm のままだと p ≈ 0.016 → **62個に1個**。
→ **「数で殴る」から「精度を上げる」への転換**が Act4–5 の山場になる。

### 6.4 等級を落とす要因（見落としやすい罠）

| 要因 | 影響 |
|---|---|
| 通常コンベアでの搬送 | 1回の落下/乗り継ぎごとに `1 − 0.002` の確率で 1段降格 → **精密トレイ搬送**で回避 |
| 熱処理後の自然冷却 | 急冷すると歪み。+σ 18% |
| 測定せずに組む | 等級は「未測定」扱い＝ B として扱われる（CMM を通して初めて S/LEGENDARY が確定する） |

## 8. 原材料の供給（資材商社：市場ではない）

**S3 の4大市場は「車と部品」の市場であり、工業原料は別系統**で供給する。

| 項目 | 仕様 |
|---|---|
| 契約 | 品目ごとに「定期便」を契約。1日1便／2日1便／週1便 |
| 価格 | `08` §2 の単価 × 相場指数（S3 §2.2 と共通）× 数量割引（1,000個以上で −8%） |
| 搬入 | 拠点の**受入ドック**（4×6）にトラックが到着し、パレットを降ろす |
| 事故 | 2.5% で遅延（1日）、0.4% で品質ばらつき増（σ +25%） |
| 設計意図 | Factorio の「鉱脈」に相当する無限供給。**ただし金とトラック動線が要る** |
