## 2. 共通ルール

### 2.1 決定論シード

```
在庫シード = hash32(saveSeed, 市場ID, チャネルID, 週番号)
個体シード = hash32(在庫シード, 連番)
```

在庫はセーブに含めず毎回再生成する（S1 §3.1）。**リロードで引き直せない。**
入札結果もシード由来なので、「セーブしてやり直す」が成立しない。

### 2.2 相場指数

```
全体指数 I(w)      = 1 + 0.18 × cos補間(ノイズ, 周期 8週)        → 0.82〜1.18（週変動 ≤0.08）
カテゴリ補正 B(s,w)= 1 ± 0.08（3週ごと更新）
為替 FX(w)         = 1 ± 0.06（輸入市場のみ・独立系列）
```

### 2.3 鑑定（情報を金で買う）

| Lv | 手段 | 費用 | 状態の表示帯 | 開示される隠しパラメータ |
|---|---|---|---|---|
| 0 | 写真と出品票だけ | ¥0 | **±0.25** | なし |
| 1 | 簡易鑑定（業者） | ¥8,000 | ±0.10 | 贋作・欠品 |
| 2 | **自社の計測ライン（CMM）** | 電力のみ | **±0.03** | **全て**（フレーム歪み含む） |

**Lv2 が無料であることが本作の構造**：工場を育てた者から順に、市場のガチャ性が消えていく。

### 3.1 チャネル `aa`：業者オークション（出品票の目利き）

#### 3.1.1 出品票（Auction Sheet）のデータ構造

```ts
interface AuctionSheet {

  score: Score;            // 評価点： "R" | "RA" | 1 | 2 | 3 | 3.5 | 4 | 4.5 | 5 | 6 | "S"
  exterior: "A"|"B"|"C"|"D";
  interior: "A"|"B"|"C"|"D";
  repaired: boolean;       // 修復歴（R / RA）
  odometerKm: number;

  notes: InspectorNote[];  // 検査員メモ（§3.1.3）
```

|---|---|---|---|

| `サビ有` | 20% | **−0.07** | `rustLevel` +0.2 |
| `下回り腐食` | 9% | **−0.12** | `rustLevel` +0.35、溶接工数 +40% |

#### 3.1.4 真の状態の生成式

```
scoreValue: R/RA→1.5, 1→1, 2→2, 3→3, 3.5→3.5, 4→4, 4.5→4.5, 5→5, 6→6, S→6.5

trueCondition = clamp(
    0.075 × scoreValue + 0.22
  + Σ(メモ補正)
  + N(0, 0.07)                       ← 評価点では消えない個体差
  , 0.05, 0.98)

frameBendMm   = repaired ? |N(0, 2.4)| + 0.6 : |N(0, 0.35)|      （>6 mm は矯正不能）
rustLevel     = clamp(0.05 + 0.004×車齢年 + メモ補正, 0, 0.95)
realOdometer  = odoStatus==="actual"   ? odometerKm
              : odoStatus==="replaced" ? odometerKm + U(40_000, 160_000)
              : U(80_000, 280_000)
```

#### 3.1.5 リアルタイム競り（POS連打）

```
開始価格 = 相場 × 0.45
2秒ごとに価格が +¥10,000（高額帯は +¥50,000）
競合業者 n = 2 + floor(U×5)（2〜6社）。各社の撤退閾値 reserve_i = fair × N(1.0, 0.18)
プレイヤーは [応札] を押し続ける。全社が撤退した瞬間に落札（＝一位価格）

fair = 車両基準価格 × (0.35 + 0.75×trueCondition) × I(w) × (repaired ? 0.72 : 1.0)
       × (odoStatus==="actual" ? 1.0 : 0.82)
```

**緊張の設計**：価格は2秒ごとに上がり続ける。降りれば0円、押し続ければ青天井。
「あと1回だけ」で予算を超える瞬間を作るため、**予算超過時は警告色になるが押せる**。

### 3.5 国内市場の独自ライン（発注仕様）

#### 3.5.1 ニコイチ合体溶接ライン

```
前方大破車（後半分が無事） ＋ 後方大破車（前半分が無事）
   ↓ [切断治具] 1,800t
   ↓ [3Dフレーム修正治具で芯出し] 3,600t    ← 歪みが残ると永久に祟る
   ↓ [突合せ溶接＋補強プレート] 5,400t
   ↓ [X線検査] 900t
ニコイチ車体（1台）

成立条件：同一シャシーID かつ 損傷部位が相補的（front/rear）
結果の歪み： frameBendMm = 0.8 + 2.2×(1 − 治具精度) + 0.6×(溶接等級の不足)
剛性       ： 元の 0.88〜1.04 倍（溶接が上手いと**純正を上回る**）
法的扱い   ： 車台番号は前方車のものを使用。**職権打刻が必要**（費用 ¥85,000・10日）
```

> ニコイチは**安いが祟る**。歪み 0.8 mm が下限なので、本気のアタック車には向かない。
> Act1–3 の「金はないが車体が要る」局面のための道である。

#### 3.5.2 AT→MT 公認換装ライン

```
入力：AT車体 ＋ MTミッション ＋ クラッチ ＋ ペダル ＋ フライホイール ＋ ハーネス ＋ ECU
工程：[降ろし 1,200t] → [フライホイール/クラッチ組付 900t] → [ペダル・マスター 600t]
      → [ハーネス加工 1,500t] → [ECU 書き換え 600t] → [構造変更申請 ※外部処理 10日]

費用：部品 ¥420,000〜 ＋ 工賃（自社なら電力のみ）＋ 公認申請 ¥68,000
結果：shift = "MT"、車重 −18 kg、driveability +0.04、**車両価値 +22%**
失敗：ハーネス加工の等級が C だと、`electricalGremlin` フラグ（夜に突然エンストする）
```

## 4. 市場2 ― 輸入車市場（保税ヤード）

**本牧・大黒埠頭の保税蔵置場。高額だが確実。** ここは「時間と金で確実性を買う」市場である。

| 項目 | 値 |
|---|---|
| 入荷 | 隔週（偶数週）。1回 4〜9 件 |
| 状態開示 | **完全**（Lv2 相当の検査済みレポートが最初から付く） |
| 価格 | 基準価格 × I(w) × **FX(w)** × 1.35（輸入プレミア） |
| 通関 | **2〜6 週**（確率分布：2週30% / 3週35% / 4週20% / 5週10% / 6週5%） |
| 税・諸費用 | 中古車関税 0% ＋ 消費税 10% ＋ 通関諸費用 ¥85,000 ＋ 保税保管 ¥3,200/日 |
| 保安基準適合 | 公道化に ¥180,000〜¥600,000 ＋ 2週（灯火類・速度計・排ガス・騒音） |

### 4.1 品目テーブル

| 品目 | 出現率 | 価格帯 | 特徴 |

| 左ハンドル納屋物件（barn find） | 22% | ¥800k–¥6,800k | état 0.25–0.65、**内外装は死んでいるが機関は当たりが多い**（乾燥地保管） |

| **航空宇宙グレード Ti-6Al-4V** | 16% | ¥9,800/kg | 工場の最上位素材。これ無しに Legendary チタン部品は作れない |
| インコネル 718 棒材 | 12% | ¥18,400/kg | タービン・バルブ |

| 絶版純正デッドストック | 15% | ¥48k–¥1,200k | 新品・無傷・等級 A。**レストアの切り札**（S4） |

### 4.2 設計意図

- **ランダム性をほぼ置かない**：ここで博打をさせない。代わりに**リードタイクと金額が痛い**。
- 「2週間後に必ず来る A級の絶版部品」と「明日わかるかもしれないコンテナ」を**並べて見せる**ことで、
  プレイヤーの時間感覚そのものを資源にする。

## 5. 市場3 ― コンテナ市場（ブラインド入札）

**港湾の差し押さえ・密輸遺棄コンテナ。中身は開けるまで分からない。**

### 5.1 入札方式：封緘（ブラインド）一位価格

```
出品数   : 週 3 + floor(Act/2)（3〜6本）
入札     : 一発勝負。金額を封筒に入れる（取り消し不可）
競合     : 2 + floor(U×5) 社（2〜6社）。各社の入札 = 推定EV × N(1.0, 0.22)
落札     : 最高額。**払うのは自分の入札額そのもの**（AA/ネトオクの二位価格とは対照的）
手数料   : 落札額の 5% ＋ 開封立会費 ¥22,000
```

> **なぜコンテナだけ一位価格か**：ブラインドだからこそ「勝者の呪い」（過大評価した者が勝つ）
> を体験させたい。二位価格で守ってしまうと、この市場の意味が消える。

### 5.2 情報の断片（ヒント）

落札前に分かるのは次だけ。**ここから中身を推定するのがこの市場の遊び**である。

| ヒント | 内容 | 読み方の例 |
|---|---|---|
| 総重量 | kg（±3%の計量誤差つき） | 950–1,700 kg 帯は車両の可能性が高い |
| 積出港 | ロングビーチ / サウサンプトン / ドバイ / 釜山 / 神戸 | 港ごとにティア分布が違う（§5.4） |
| 税関メモ | 「書類不備」「申告：機械部品」「内容相違」「危険物なし」 | 「内容相違」は当たりも外れも大きい |
| 封印番号 | 封印が破られた形跡の有無 | 破封済み＝**抜かれている**（ティア −1） |
| **X線シルエット**（Act4 解放） | 「車両らしき輪郭」「円筒形が多数」「空洞が多い」「金属密度が高い」 | 事後確率を更新できる＝**情報への投資** |

## 7. 抽選アルゴリズム（擬似コード）

```ts
function generateWeek(ctx: MarketContext): WeeklyMarket {
  const I = marketIndexAt(ctx.saveSeed, ctx.week);

  // ── 1. 国内中古 ──
  const aa = times(18 + 2 * ctx.act, i => {
    const r = rngOf(ctx, "aa", i);
    const score      = weightedPick(r, SCORE_DISTRIBUTION);        // §3.1.2
    const notes      = rollNotes(r, score);                        // §3.1.3
    const trueCond   = 0.075 * scoreValue(score) + 0.22
                     + sum(notes.map(n => n.delta)) + gauss(r, 0, 0.07);
    return buildSheet(r, score, notes, clamp(trueCond, 0.05, 0.98), I);
  });
  const netauc  = times(14 + 2 * ctx.act, i => rollNetAuction(ctx, i, I));
  const yard    = times(12 + floor(rng() * 19), i => rollYardCar(ctx, i, I));
  const bluebin = rollBlueBins(ctx, I);

  // ── 2. 輸入（隔週） ──
  const imports = ctx.week % 2 === 0 && ctx.act >= 2
    ? times(4 + floor(rng() * 6), i => rollImport(ctx, i, I, fxAt(ctx.saveSeed, ctx.week)))
    : [];

  // ── 3. コンテナ ──
  const containers = ctx.act >= 3
    ? times(3 + floor(ctx.act / 2), i => {
        const r    = rngOf(ctx, "container", i);
        const port = weightedPick(r, PORT_DISTRIBUTION);
        const tier = weightedPick(r, applyPortBias(TIER_TABLE, port));   // §5.3 §5.4
        return { port, tier, weightKg: rollWeight(r, tier),              // §5.5
                 customsNote: rollNote(r), sealBroken: r() < 0.14,
                 contents: rollContents(r, tier) };                      // §5.6
      })
    : [];

  // ── 4. ローカル ──
  const local = ctx.heat >= 70 ? [] : rollLocalOffers(ctx);              // §6.3

  return { week: ctx.week, marketIndex: I, aa, netauc, yard, bluebin, imports, containers, local };
}
```
