# S4. レストア工程 ― ステートマシン設計

> 対象：Sim Programmer / Lead Designer ／ 実装：`shared/midnight/restore.ts`（テスト `restore.test.ts`）
> 「サビ進行度 80% 以上の不動車」を、**新車を凌駕する車体**へ再生するための全工程を定義する。

---

## 1. 設計の狙い

レストアは**工場のサブセットではなく、工場の最終試験**である。
サンドブラスト、電着塗装、フレーム修正、5軸削り出し——R&Dファクトリーで育てた設備が
ここで一本の長いラインとして繋がる。そして出てくるのは、**部品ではなく「車体そのもの」**。

| 原則 | 内容 |
|---|---|
| P1 | **工程は飛ばせない**。歪みを残したまま塗ると、その歪みは永久に残る |
| P2 | **各工程に固有の失敗がある**。やり直せるが、時間と素材を失う |
| P3 | **完成品は新車を超える**（剛性 +42% まで）。それが 1,000 時間を注ぐ理由になる |
| P4 | 進行は**ゲーム日単位**で可視化する。「あと6日」が見えていること |

## 2. 入力：レストア対象車（RestoreSubject）

```ts
interface RestoreSubject {
  chassisId: ChassisId;
  source: "container" | "import" | "yard" | "aa" | "netauc";
  rustLevel: number;        // 0.0–1.0（対象は 0.80 以上）
  frameBendMm: number;      // 0–8（>6 は要・特殊治具）
  missingParts: PartSlot[]; // 欠損（廃盤部品は作るしかない）
  seizedEngine: boolean;    // 固着
  panelDamage: Record<PanelId, number>;  // 0–1、12パネル
  numberingOk: boolean;     // 車台番号が読めるか（読めないと職権打刻）
  provenance?: "prototype" | "works" | "normal";  // T5 コンテナ由来など
}
```

**本ラインの主対象は、発注仕様で指定された S30Z** ——
日産 フェアレディZ 432（S30・1970年・S20 型 2.0L 直6 DOHC・1,040 kg）である。
ガレージの奥、あるいは地方の解体ヤードや海外の納屋で 30 年放置され、
**サビ進行度 0.80〜0.95・不動・欠損多数**の状態でしか市場に現れない（`spec/S3` §3.3 / §5）。

典型値（コンテナ T3 由来の S30Z）：`rust 0.86 / bend 3.2 mm / missing 7点 / seized true`。

> **実際の入手例**（seed 20261016・第6週・コンテナ市場）
> 釜山発・1,086 kg・税関メモ「危険物なし」・封印健全・X線「車両らしき輪郭」
> → 事後確率 **T3 91.4%**、期待値 ¥1,637,249、競合最高 ¥2,071,800
> → 開封：**T3 不動車両：日産 フェアレディZ 432**（評価額 ¥1,348,700）
> ここから §3 の 13 工程が始まる。

## 4. 各工程の数式

### 4.1 S3 サンドブラスト剥離

```
剥離率        = clamp(0.55 + 0.4 × (研削材供給 / 180 kg) + 0.1 × 圧空圧力係数, 0, 1)
残存サビ      = rustLevel × (1 − 剥離率)
吹き抜け確率  = 0.06 + 0.35 × max(0, rustLevel − 0.85) + 0.2 × (圧力係数 − 1.0)
  → 吹き抜けたパネルは missingPanels に追加（S6 行き）
所要 tick     = 21,600 × (0.6 + 0.8 × rustLevel)
```

> **サビが深いほど、剥離で穴が開く。** 80% 超の個体は「パネルを作る覚悟」が前提になる。

### 4.2 S5 カチオン電着浸漬槽

```
膜厚 μm       = 18 × (電圧係数 V) × (浸漬時間 / 標準) ^ 0.45
均一度 U      = clamp(1 − 0.08 × |V − 1.0| × 10 − 0.15 × (液温ずれ℃ / 5), 0.4, 1.0)
防錆係数 R    = clamp(0.35 + 0.65 × U × (膜厚 / 20 μm 正規化), 0, 1.0)
   → 以後の rustReturnRate = 0.004 × (1 − R) /ゲーム日
重量増        = +6.2 kg × (膜厚 / 18 μm)
```

**この工程だけはやり直せない**（既に塗られた車体は再ブラストから）。
電圧と液温の設定が、10年後のサビ再発率を決める——という**時間差のフィードバック**を持つ。

### 4.3 S6 板金・欠損パネル製作

| パネル材 | 1枚の時間 | 重量 | 剛性寄与 | コスト |
|---|---|---|---|---|
| 鋼板（純正相当） | 7,200 t | 基準 | 1.00 | ¥18,000 |
| アルミ | 9,000 t | ×0.62 | 0.88 | ¥46,000 |
| **ドライカーボン**（S2 §3.3） | 14,400 t | **×0.34** | 1.06 | ¥120,000 相当 |

```
所要 = Σ(パネルごとの時間) × (1 + 0.15 × 損傷度)
寸法精度 = 等級依存。C 級だと建て付け不良 → 空力 Cd +0.008、見た目に段差
```

### 4.4 S7 廃盤部品の3Dスキャン＆5軸削り出し

```
[3Dスキャナ 300t] 現物（片側だけ生きている等）→ 点群 → 面張り → CAD
   ※ 現物が無い場合：図面データを市場（S3 輸入/ローカル）で買うか、
     スパコンで「形状推定」（180,000 問題規模・精度 Q に依存）

[5軸マシニング 540t/個] 素材 → 複製部品
   等級 = S2 §6.2 の公差式に従う（恒温室とCMMがあれば A〜LEGENDARY）
   コスト = 素材費 + 電力。純正新品が買えない以上、**精度は自分の工場の精度そのもの**
```

> ここが本作の思想の結節点：**廃盤部品は「買う」ものではなく「作れるようになる」もの。**
> 工場の σ が小さいほど、レストアの質が上がる。

### 4.5 S8 3Dフレーム修正治具

```
1サイクル（3,600 tick）あたりの矯正量：
  Δbend = min(残存歪み, 0.9 mm) × 治具精度 k_jig × (1 − 0.15 × 残存サビ)
     k_jig: 簡易治具 0.65 ／ 3D治具 1.00 ／ 3D治具+レーザー計測 1.18

引きすぎ事故： p = 0.12 × (1 − 治具精度) + 0.06 × (Δ要求 / 0.9)
     発生時： bend が反対方向に (0.4〜1.2) mm 増える＝サイクルが戻る

必要サイクル数 ≈ ceil(frameBendMm / 0.9 / k_jig)
   例：3.2 mm → 4 サイクル（14,400 tick ＝ 0.5 ゲーム日）
       7.8 mm → 9 サイクル ＋ 事故リスク（**専用の大型治具が必要**）
```

**矯正の残差 `residualBendMm` は、最終剛性に直結する**（§5）。
0.3 mm 以下に追い込めれば「新車以上」の領域に入る。

### 4.6 S9 スポット増し＋構造用接着

```
増し打ち点数 N = 0 〜 420 点（プレイヤーが指定。1点 24 tick）
接着剤長 L     = 0 〜 32 m（1 m 220 tick）

剛性ボーナス：
  spotBonus = 0.12 × (N / 420) ^ 0.8          最大 +12%
  glueBonus = 0.08 × (L / 32) ^ 0.9           最大 +8%
  cageBonus = ロールケージ等級 × 0.22          最大 +22%（LEGENDARY ケージ）
重量増      = N × 0.004 kg + L × 0.21 kg + ケージ 28 kg
```

## 5. 完成時の性能（新車超えの定義）

```
stiffnessFactor =
    (1 + spotBonus + glueBonus + cageBonus + panelBonus)
  × (1 − 0.045 × residualBendMm)
  × (1 − 0.08  × residualRust)
  × (1 − 0.06  × (水素脆化 ? 1 : 0))

  panelBonus = ドライカーボンでパネルを作った場合のみ +0.02

完全レストアの例：
  spot 420点(+0.12) + 接着32m(+0.08) + S級ケージ(+0.19) = 1.39
  残存歪み 0.2 mm → ×0.991 ／ 残存サビ 0.04 → ×0.997
  → stiffnessFactor = **1.374**（新車比 +37%）
```

### 5.0 実装検証値（`restore.test.ts`）

対象＝コンテナ T3 由来の納屋物件（サビ 0.86 / 歪み 3.2 mm / 欠損 7 点 / 損傷パネル 3 枚）。

| プラン | 剛性 | 所要 | 費用 | 電力 | 追加質量 | 残存歪み | 防錆 |
|---|---|---|---|---|---|---|---|
| 既定（スポット240・接着16m・ケージ0.6・鋼板・3D治具） | **1.179** | 9.1 日 | ¥1,722,800 | 約 160 kWh | +26 kg | 0.3 mm | 0.96 |
| **全部盛り**（420・32m・LEGENDARYケージ・カーボン・レーザー治具） | **1.439** | 9.5 日 | ¥2,318,800 | 199 kWh | +26.2 kg | **0.01 mm** | 0.961 |
| 補強ゼロ | **0.93** | 8.2 日 | ¥0.9M 級 | — | +6 kg | 0.3 mm | 0.96 |

**費用は約 230 万円、工期は約 10 日。** これを「たった1台のため」に払う——その重さが、
この工程をミニゲームではなく**決断**にする。

### 5.1 ラップタイムへの効き方（S5 §6 と接続）

```
実効グリップ μ_eff = μ0 × clamp(0.88 + 0.12 × stiffnessFactor, 0.60, 1.05)

  stiffnessFactor 0.59（歪んだ事故車）→ ×0.951 → **μ −4.9%**  ≒ 筑波 +1.0 秒
  stiffnessFactor 1.00（新車）        → ×1.000 → 基準
  stiffnessFactor 1.37（完全レストア）→ ×1.044 → **μ +4.4%** ≒ 筑波 **−0.9 秒**
```

> **納屋で朽ちていた車体が、最終的に新車より 0.9 秒速い。**
> これが「放置レジェンド車を蘇らせる」ことのゲーム内での正当化である。
> 加えて `driveability +0.05`（車体がヨレないので曲がる）、NVH 改善、車両価値 ×2.4。

### 5.2 副次効果

| 項目 | 効果 |
|---|---|
| 車重 | サビ除去 −8 kg、電着 +6 kg、増し打ち +1.7 kg、接着 +6.7 kg、ケージ +28 kg → **+34 kg** |
| 耐久 | `heatCycles` 耐性 +40%、疲労寿命 ×1.8 |
| 価値 | 車両評価額 ×2.4（売ればいい金になる。**だが売らない**） |
| REP | 完成時 +15。首都高で「あれ、あの個体か？」と認識される |

## 6. 失敗モードとリカバリ

| 失敗 | 発生工程 | 影響 | リカバリ |
|---|---|---|---|
| 固着ボルト破断 | S2 | +0.3 日、ボルト新造 | 自動（時間のみ） |
| **薄板の吹き抜け** | S3 | パネル欠損が増える | S6 でパネル製作（時間・金） |
| 水素脆化 | S4 | 強度 −6%（**恒久**） | 焼鈍処理で半減（+0.5日） |
| 膜厚ムラ | S5 | 防錆 −30%（**恒久**） | 再ブラスト（S3 からやり直し） |
| パネル寸法不良 | S6 | 素材ロス | 作り直し |
| 引きすぎ | S8 | 歪みが逆方向に増加 | サイクルを追加（事故が連鎖しうる） |
| 打点不良 | S9 | spotBonus 半減 | 追い打ち可（+0.2日） |
| 配線ミス | S11 | 夜に突然エンスト | S12 で発覚 → 原因究明ミニゲーム |

> **恒久的な失敗が2つだけある**（水素脆化・膜厚ムラ）。
> すべてやり直せると緊張が消え、すべて恒久だと理不尽になる。この比率が設計点である。
