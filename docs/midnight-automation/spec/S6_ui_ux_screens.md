# S6. UI/UX ― 画面遷移・操作レイアウト案

> 対象：UI Designer / Frontend ／ 前提：S1（シーン定義）
> 命題：**「Factorio の俯瞰画面」と「コックピット視点」を、ロード画面なしで同じ世界として繋ぐ。**

---

## 1. UI 設計の三原則

| # | 原則 | 具体 |
|---|---|---|
| **A** | **世界の中にUIを置く** | 工場の指標は「壁の制御盤」、車の指標は「メーターパネル」。浮いたHUDを最小化 |
| **B** | **遷移で切らない** | シャッターが開き、カメラが**俯瞰 → 車高 1.1 m** へ下りる。1.8 秒。その間も入力可 |
| **C** | **1画面に1つの決断** | 情報は多くていい。だが「いま押すべきボタン」は常に1つだけハイライトする |

**カラー**：ベース `#0B0E12`（深夜の路面）／工場アクセント `#F2A33C`（作業灯のオレンジ）／
首都高アクセント `#2BE3FF`（ナトリウム灯に対するシアン）／警告 `#FF3B4E`。
**フォント**：等幅は `JetBrains Mono`、日本語見出しは角ゴシック（90年代のサービスマニュアル風）。

## 3. シームレス遷移の肝 ―「シャッター」

```
t=0.00  [工場俯瞰] プレイヤーがヒーローカーを選択 → 「出る」
t=0.10  カメラが車へズーム開始。工場のUI（レシピ窓・物流線）がフェードアウト
t=0.35  シャッターのモーター音。工場の環境音（コンプレッサ・コンベア）が減衰し始める
t=0.60  シャッターが開く。外のネオンと雨音が**隙間から漏れてくる**（音が先、絵が後）
t=0.90  カメラが俯瞰 65° → 車高 1.1 m・視野 8° へ補間（ease-in-out-cubic）
t=1.20  メーターパネルが下から**物理的にせり上がる**（HUDではなく車の一部）
t=1.50  エンジン始動。タコメーターの針が一度振り切れて戻る
t=1.80  操作権がプレイヤーへ。合流レーンの白線が流れ出す
```

**技術的には同一シーングラフ**：工場タイルマップと首都高メッシュは同じ `WorldState` の
別レイヤとして常駐し、カメラと入力マップだけが切り替わる（S1 §2）。
ロード画面は**一度も出さない**。

> 逆方向（帰還）はもっと静かにする。拠点のシャッター前で停車 → 3 秒待つ → 開く → 入る。
> 「帰ってきた」という感覚のために、**帰りだけは少し長く**する。

```
├──────────────┴──────────────────────────────────────────┴───────────────┤
│ 🏭 工場 │ 🔬 研究 │ 🔧 レストア │ 🛒 市場 │ 🏎 ビルド │        [ 夜へ出る ] │ ← 下部タブ
└─────────────────────────────────────────────────────────────────────────┘
```

**Factorio 流儀を守る点**：
- `Q`＝スポイト（コピー）、`R`＝回転、`Shift+クリック`＝設計図、`Alt`＝オーバーレイ常時表示。
- **オーバーレイは4系統**：物流（アイテム流量）／電力（消費ヒートマップ）／**熱**（室温勾配）／**騒音**（dB 等高線）。
- アラートは「止まっている機械」を**赤い感嘆符**で地図上に出し、クリックで飛ぶ。

**本作独自の点**：
- 右ペインに常に **「この部品の等級と σ」** が出る。工場の目的が生産量ではなく**精度**だから。
- 左下に **近隣苦情メーター**。騒音が続くと「苦情」イベント（夜間の操業停止）。
- 上部バーの `[ 夜へ出る ]` は **22:00 を過ぎると発光する**。

## 7. DRIVE 画面（コックピット視点）

```
                     ╲                                   ╱
                      ╲   [ 疑似3D・首都高 C1 ]          ╱
                       ╲      雨の路面反射                ╱
     ┌──────────┐        ╲      ネオンの滲み             ╱
     │ 🗺 C1外回り│         ╲                            ╱
     │  谷町JCT  │          ═══════════════════════════
     │   ▲0.8km │
     └──────────┘      ╔════════════════════════════════╗
                       ║  ╭────╮  ╭────────╮  ╭────╮    ║ ← 物理的なメーターパネル
   ┌─ ライバル ──┐      ║  │水温│  │ 9,200  │  │油温│    ║   （HUDではない）
   │ 暁 / R-33  │      ║  │ 94 │  │  rpm   │  │108 │    ║
   │ 差 +0.4s   │      ║  ╰────╯  ╰────────╯  ╰────╯    ║
   │ ▓▓▓▓▓▓░░░░ │      ║        247 km/h    6速          ║
   └────────────┘      ║  🔴ログテープ REC 00:04:12      ║
                       ╚════════════════════════════════╝
```

| 要素 | 配置 | 設計意図 |
|---|---|---|
| **水温・油温** | メーター内（中央左右） | **ヒートゲージこそが本作の緊張**。レッドゾーンで出力が落ちる |
| 速度・回転 | 中央 | 針は物理シミュレーション（オーバーシュートする） |
| ミニマップ | 左上・小さく | 首都高は**覚えるもの**。地図に頼らせすぎない |
| ライバル差分 | 左中 | SPバトル時のみ |
| **走行ログ REC** | メーター下 | 回っている間ずっと赤点灯。**トラブルが起きるほど価値が上がる** |
| 一般車警告 | 画面端の**周辺視フラッシュ** | トラック・タクシーを縫う緊張 |

**雨の表現**：フロントガラスの水滴（視界を物理的に奪う）＋ 路面のネオン反射（縦に伸びる）
＋ ワイパー（周期的に視界が戻る）。**ワイパー速度は手動**。

**操作（ゲームパッド）**：
`RT` アクセル／`LT` ブレーキ／`LS` ステア／`A` シフトアップ・`B` ダウン／
`LB` ワイパー／`RB` **ログテープ マーカー**（「いまの挙動を記録」＝後でスパコンが重点解析）／
`Y` ミニマップ拡大／`背面` リプレイ。

## 9. アクセシビリティ・その他

| 項目 | 対応 |
|---|---|
| 色覚 | 限界要因の色分けは**色＋パターン**（斜線／網掛け／点）で二重化 |
| テキスト | 3 段階スケール。出品票だけは**専用に大きめ**の設定を別に持つ |
| 操作 | フルリマップ。工場はマウスのみ／ゲームパッドのみで完結 |
| 運転支援 | ライン表示・ABS・TCS を個別 ON/OFF（**ゲート時間には影響しない**） |
| 酔い | 疑似3Dの画面揺れ・モーションブラー・FOV を個別に調整可 |
| 言語 | 日本語／英語。**車種名と標識は日本語のまま**（雰囲気の核） |

## 10. 実装メモ（React / Babylon.js）

```
src/
  scenes/
    GarageHub.tsx      … shadcn/ui Tabs。常駐の上部バー
    Factory.tsx        … Canvas 2D（タイルマップ・WebGL2 インスタンシング）
    DriveScene.tsx     … Babylon.js。工場シーンと同じ Engine インスタンスを共有
    Shutter.tsx        … カメラ補間のみ。**両レイヤを同時に描画**する唯一の場所
  hud/
    MeterPanel.tsx     … CSS Houdini + Canvas。針は spring 物理
    SensitivityView.tsx… lap-solver を Worker で叩き、差分を表示
  state/
    worldStore.ts      … Zustand。tick は RAF ではなく固定 50 Hz のアキュムレータ
```

**重要**：`Shutter` を独立シーンにせず、**FACTORY と DRIVE の両方をマウントしたまま**
カメラだけを動かす。これがロード画面ゼロの実装的な核心である。
GPU 負荷は、遷移中だけ工場の更新頻度を 50 Hz → 5 Hz に落として吸収する。
